# rclone VPS

Application personnelle utilisée uniquement par son propriétaire pour sauvegarder
son propre serveur vers son propre Google Drive, avec rclone.

## Règles de confidentialité

- Une seule personne utilise cette application : son propriétaire.
- L'accès est limité aux fichiers créés par l'application (scope `drive.file`).
- Aucune donnée n'est collectée, analysée, vendue ni partagée avec des tiers.
- Les sauvegardes sont chiffrées avant envoi (rclone crypt).
